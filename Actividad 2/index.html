CSS

Que es?

Cuando habalmos de CSS nos referimos a un lenguaje,una hoja de estilo en cascada que se usa para darle otra apariencia a las paginas html.(parrafo identificado con solo selector, color letra)

Para que sirve?

Podemos estilizar un sitio web como queramos ya sea poner algun color, distina fuente en la tipografia hasta animarla poniendo efectos visuaes.(parrafo identificado con id, letra en bold)

TAmbien es util para que la pagina se adapte a distintos tamaños de pantallas/dispositivos(parrafo identificado con class,color fondo)
